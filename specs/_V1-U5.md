## Rulings asked for

**RZ-80 — the reading of "incompatible with the commutation relations".** Printed (§13.2, p31): "The parities are inconsistent. A multiplicative ℤ2 grading is therefore incompatible with the commutation relations." The spec's reading — under a ZMod 2 grading with Ĥ even and Ê, Ŝ, D̂ odd, (3.2) forces [Ê, Ŝ] = 0 ∧ ĤD̂ = 0 — is the faithful one and true. Reasons: (a) "a grading compatible with relations" means, in standard usage, that the relations are homogeneous; the printed argument is exactly a homogeneity check of (3.2) and proves exactly its consequence; (b) the print nowhere invokes nonzero or faithful operators here, while the same section (§13.3) names invertibility explicitly when it means it — so the "no graded realization by nonzero operators exists" reading is not the paper's meaning; (c) that reading is false: the spec's §6 realization in (ℂ[ε]/ε²)², Ê = (ε, 0), Ĥ = (1, 0), Ŝ = D̂ = (0, ε), re-checked as 4 × 4 block matrices: all four relations hold as 0 = 0 with every operator nonzero. So no CC. Taking (3.2) alone is right: the argument uses (3.2) alone, and the theorem then implies the plural conclusion. (Optional, not needed for fidelity: under the §13.3 invertible reading the stronger "no graded realization" does hold — Ĥ a unit and ĤD̂ = 0 force D̂ = 0 — but the print does not say this at §13.2, so the spec rightly leaves it out.)

**RZ-81 — the conjunction.** The theorem is `(six relations, ħ ≠ 0 ⇒ D̂ÊĤ = 0 ∧ (Nontrivial A → ¬ all units)) ∧ (∀ ħ, ∃ nonzero 2 × 2 realization of all six)`. Both legs are printed in one sentence ("This is impossible when D̂, Ê, Ĥ are invertible …, though not for arbitrary nonzero operators; (13.5) is therefore a strong constraint on any representation rather than an outright contradiction [D]"), so they ride together correctly. Leg (b) at "all six relations realized by nonzero operators" is the faithful strength: "rather than an outright contradiction" is about the system, so the weaker "D̂ÊĤ = 0 with nonzero factors" would under-read it. The witness N = !![0, 1; 0, 0] (N² = 0) is trivial but sufficient — the print says "arbitrary nonzero operators". Derivation re-done by hand: [[Ê,Ĥ],D̂] = c[Ŝ,D̂]D̂ = c²ÊĤD̂; [[Ĥ,D̂],Ê] = −cÊ[Ê,Ŝ] = −c²ÊĤD̂; [[D̂,Ê],Ĥ] = c[Ŝ,Ĥ]Ĥ = c²D̂ÊĤ; sum c²D̂ÊĤ, c = iℏ.
