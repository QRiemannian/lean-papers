## 3 · Formal reading
- **φ** is the Λ-ratio of (7.5), *as defined* at L:RZ-46a: φ(s) := Λ(2s − 1)/Λ(2s), Λ = `completedRiemannZeta` (Lean name `scatteringRatio`, shared with L:RZ-46a). Its identification with the scattering determinant (L:RZ-46b) is not used.
- **"a zero ρ"** — the sentence follows "The Riemann zeros are poles of φ(s)", so ρ ranges over the non-trivial zeros of ζ. Read in mathlib's own vocabulary (the hypotheses of `RiemannHypothesis`): `riemannZeta ρ = 0`, `ρ` not a trivial zero (`¬ ∃ n : ℕ, ρ = -2 * (n + 1)`), and `ρ ≠ 1`. This reading does **not** assume 0 < Re ρ < 1 — that is exactly what the "unconditionally" clause asserts, so it is proved, not assumed.
- **"contributes a pole at s = ρ/2"** — read as: φ(s) is unbounded as s → ρ/2, i.e. `Tendsto scatteringRatio (𝓝[≠] (ρ / 2)) (Bornology.cobounded ℂ)` (equivalently, for φ meromorphic at ρ/2, `meromorphicOrderAt scatteringRatio (ρ / 2) < 0`, via `tendsto_cobounded_iff_meromorphicOrderAt_neg`). The content: Λ(2s) → Λ(ρ) = 0 at s = ρ/2 while the numerator Λ(2s − 1) → Λ(ρ − 1) = Λ(2 − ρ) ≠ 0 (Re(2 − ρ) > 1), and Λ(2s) ≠ 0 on a punctured neighbourhood (isolated zeros).
- **"under RH these poles lie on Re(s) = 1/4"** — `RiemannHypothesis → (ρ / 2).re = 1 / 4`.
- **"(unconditionally in the open strip 0 < Re(s) < 1/2)"** — `0 < (ρ / 2).re ∧ (ρ / 2).re < 1 / 2`, i.e. every non-trivial zero has 0 < Re ρ < 1 (from `riemannZeta_ne_zero_of_one_le_re` for Re ≥ 1, and its reflection through `riemannZeta_one_sub` for Re ≤ 0, where the cases ρ = −(2m + 1) and ρ = 0 are excluded by ζ(0) = −1/2 and by `riemannZeta_neg_nat_eq_bernoulli` with B_{2k} ≠ 0 — itself read off `riemannZeta_two_mul_nat` and ζ(2k) ≠ 0).
- **"— not on Re(s) = 1/2"** — (ρ/2).re ≠ 1/2; it follows from the strip clause, and is stated so the statement carries every printed clause.
- The row speaks of the poles *contributed by zeros*; it does not claim these are all the poles of φ (φ also has a pole at s = 1 from Λ(2s − 1)), and the spec does not add that claim.

## 5 · Intended Lean statement
Prose: let ρ be a non-trivial zero of ζ (ζ(ρ) = 0, ρ not a trivial zero, ρ ≠ 1). Then φ = `scatteringRatio` tends to infinity at ρ/2 (a pole); if RH holds, Re(ρ/2) = 1/4; and unconditionally 0 < Re(ρ/2) < 1/2, so Re(ρ/2) ≠ 1/2.

```lean
/-- L:RZ-47 — RZ §7.4 p19 (echo §5.4 p14): zeros of ζ give poles of φ(s) = Λ(2s−1)/Λ(2s) at s = ρ/2. -/
theorem rz_47_zero_gives_pole (ρ : ℂ) (hζ : riemannZeta ρ = 0)
    (hnt : ¬ ∃ n : ℕ, ρ = -2 * (n + 1)) (h1 : ρ ≠ 1) :
    Filter.Tendsto scatteringRatio (nhdsWithin (ρ / 2) {ρ / 2}ᶜ) (Bornology.cobounded ℂ) ∧
    (RiemannHypothesis → (ρ / 2).re = 1 / 4) ∧
    (0 < (ρ / 2).re ∧ (ρ / 2).re < 1 / 2) ∧
    (ρ / 2).re ≠ 1 / 2 := by sorry
```
(`scatteringRatio` as in L:RZ-46a.)
