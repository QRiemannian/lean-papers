## 3 · Formal reading
- **Which character.** Modulo 5 there are three non-trivial Dirichlet characters (one of order 2, two of order 4), so "the non-trivial character mod 5" alone does not pick one. "Quadratic Gauss sum" does: it is the Gauss sum of the quadratic character. χ₅ is therefore the Legendre character a ↦ (a/5) on ZMod 5, formally `quadraticChar (ZMod 5) : MulChar (ZMod 5) ℤ`, pushed to ℂ by `MulChar.ringHomComp` with `Int.castRingHom ℂ`. This agrees with the paper's own later definition (§9.2: the Kronecker symbol (5/·), the real primitive character of conductor 5): as functions on residues mod 5, (5/a) = (a/5) (quadratic reciprocity, 5 ≡ 1 mod 4; at a = 2 both are −1). Values: χ₅(0) = 0, χ₅(1) = χ₅(4) = 1, χ₅(2) = χ₅(3) = −1.
- **Which additive character (convention named).** τ(χ) = Σ_{a mod 5} χ(a) ψ(a) with ψ(a) = e^{2πia/5}, mathlib's `ZMod.stdAddChar (N := 5)` (`ZMod.stdAddChar_coe : stdAddChar (j : ZMod N) = exp (2 * π * I * j / N)`). The paper does not print ψ; the standard additive character is the reading. **The sign is convention-dependent and is the content of the row:** for ψ_k(a) = e^{2πika/5} one has τ_{ψ_k}(χ₅) = χ₅(k)·τ_{ψ_1}(χ₅), so k = 1 or 4 gives +√5 and k = 2 or 3 gives −√5. With the standard ψ (k = 1): τ = ζ + ζ⁴ − ζ² − ζ³ = 2cos(2π/5) − 2cos(4π/5) = 2·((√5 − 1)/4 + (√5 + 1)/4) = √5, ζ = e^{2πi/5}. (Since χ₅(−1) = 1, τ is real and complex conjugation of ψ does not change it.)
- **√5** is the positive real square root, `Real.sqrt 5`, cast to ℂ.
- **Mathlib route (E2, as the brief records).** `gaussSum_sq` with `quadraticChar_ne_one`, `quadraticChar_isQuadratic` (composed by `MulChar.IsQuadratic.comp`), `ZMod.isPrimitive_stdAddChar` gives τ² = χ₅(−1)·5 = 5 (`quadraticChar_neg_one` → `ZMod.χ₄` at 5 ≡ 1 mod 4, `ZMod.χ₄_nat_one_mod_four`). That fixes τ = ±√5; the sign comes from evaluating the real part with `Real.cos_pi_div_five` (cos(2π/5) = 2cos²(π/5) − 1, cos(4π/5) = −cos(π/5)). The general Gauss sign theorem is not needed at p = 5.
- **Instance note.** `ZMod 5` is a field only under `Fact (Nat.Prime 5)`; no such global instance exists at the pin (`/usr/bin/grep` finds `Nat.fact_prime_two` and `Nat.fact_prime_three` at Mathlib/Data/Nat/Prime/Defs.lean:469, :472, and a ℕ+ `fact_prime_five` at Mathlib/Data/PNat/Prime.lean:124 — none for the natural number 5). L supplies a local instance; it is a provable fact, not an added hypothesis.

## 5 · Intended Lean statement
**Prose.** Let χ₅ be the quadratic (Legendre) character modulo 5, with values in ℂ, and ψ the standard additive character a ↦ e^{2πia/5} on ℤ/5ℤ. Then the Gauss sum Σ_a χ₅(a)ψ(a) equals the positive real number √5.

**Proposed signature.**
```lean
local instance : Fact (Nat.Prime 5) := ⟨by norm_num⟩

/-- χ₅: the quadratic character mod 5, valued in ℂ (the Legendre symbol (·/5)). -/
noncomputable def chi5 : MulChar (ZMod 5) ℂ :=
  (quadraticChar (ZMod 5)).ringHomComp (Int.castRingHom ℂ)

theorem rz_11_gaussSum_chi5 :
    gaussSum chi5 (ZMod.stdAddChar (N := 5)) = (Real.sqrt 5 : ℂ) := by
  sorry
```
The statement is an equality with the explicit sign (+√5); it is neither the weaker τ² = 5 nor a statement for every primitive ψ (which would be false).
