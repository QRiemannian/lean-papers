## 3 · Formal reading
- **Phase space and H.** Phase space ℝ² with coordinates (x, p); H_cl(x, p) = x·p.
- **"the classical trajectories" (convention named).** Solutions of Hamilton's equations ẋ = ∂H/∂p, ṗ = −∂H/∂x. For H = xp: ∂H/∂p = x, ∂H/∂x = p, so the system is ẋ = x, ṗ = −p. The print does not write the equations; the spec names the standard sign convention (ẋ = +∂H/∂p). With the opposite convention the trajectories would be x₀e^{−t}, p₀eᵗ and (6.4) would be false, so the convention is fixed by the display.
- **(6.4) as "the" trajectories.** Two directions: (a) existence — t ↦ (x₀eᵗ, p₀e^{−t}) solves the system with initial point (x₀, p₀); (b) "the" — every differentiable solution with that initial point is this one. The spec takes both; (b) is the reading of the definite article and is the one thing V₁ should weigh (§ summary).
- **"are hyperbolic".** Read as: each trajectory lies on the level set x·p = x₀p₀ of H (a hyperbola when x₀p₀ ≠ 0; a coordinate half-axis or the origin otherwise), with x expanded and p contracted at the exponential rates e^{±t}. The exponential rates are (6.4) itself; the formal addition is the conservation x(t)p(t) = x₀p₀ for all t.
- **"they never return".** For an initial point (x₀, p₀) ≠ (0, 0), the trajectory visits no point twice: t ↦ (x(t), p(t)) is injective. **Hypothesis supplied:** (x₀, p₀) ≠ (0, 0). The origin is a fixed point of the flow (a constant trajectory), for which "never return" fails trivially; the print does not exclude it. The spec supplies the exclusion as a wording note (the standard reading of "trajectories … non-periodic motion" excludes the equilibrium), not as a CC; V₁ decides.

## 5 · Intended Lean statement
**Prose.** Let H(x, p) = x·p. (o) ∂H/∂p at (x, p) is x and ∂H/∂x at (x, p) is p. For every initial point (x₀, p₀) ∈ ℝ², with X(t) = x₀eᵗ, P(t) = p₀e^{−t}: (a) X(0) = x₀, P(0) = p₀, and for all t, X′(t) = X(t), P′(t) = −P(t); (b) any differentiable x, p : ℝ → ℝ with x′ = x, p′ = −p, x(0) = x₀, p(0) = p₀ equal X, P; (c) X(t)·P(t) = x₀p₀ for all t; (d) if (x₀, p₀) ≠ (0, 0), t ↦ (X(t), P(t)) is injective.
