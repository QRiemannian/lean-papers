3. **Formal reading**
   - **(8.1)** z = x + iy ∈ ℍ; for f : ℂ → ℂ (a function on ℍ is evaluated at points with y > 0), Δf(z) = −y²(∂²f/∂x² + ∂²f/∂y²)(z). In Lean the bracket is the Euclidean Laplacian of ℂ as a real inner product space: `iteratedFDeriv ℝ 2 f z ![1, 1] + iteratedFDeriv ℝ 2 f z ![Complex.I, Complex.I]`, which mathlib identifies with `Laplacian.laplacian f z` (notation Δ) by `InnerProductSpace.laplacian_eq_iteratedFDeriv_complexPlane`. Sign convention: the paper's Δ carries the leading minus as printed; the Lean definition carries the same minus. "on the modular surface" (functions invariant under SL(2, ℤ)) restricts the domain of application, not the formula; the definition is pointwise and the invariance is not part of it.
   - **(8.2)** {·} is the fractional part, `Int.fract`. T(x) = Int.fract (x⁻¹). **Convention at x = 0:** the printed formula is undefined at x = 0 (1/0); Lean's `(0 : ℝ)⁻¹ = 0` gives T(0) = Int.fract 0 = 0, which is the standard convention for the Gauss map. The spec names this; it is the one place the Lean definition says something the print does not (see the unit summary). The typing claim "T : [0, 1) → [0, 1)" is: x ∈ [0, 1) ⇒ T(x) ∈ [0, 1).
   - **(8.3)** s ∈ ℂ; f : ℝ → ℂ; x ∈ [0, 1) so x + n ≥ 1 > 0; (x + n)^{−2s} is the principal complex power of the positive real x + n, `((x + n : ℝ) : ℂ) ^ (-2 * s)` (`Complex.cpow`, which for a positive real base is exp(−2s log(x + n))). The sum runs over n = 1, 2, …, written in Lean over `n : ℕ` with n + 1. **The series is defined by `tsum`**, which returns 0 where the family is not summable; the print gives no domain for s or f, and the definition agrees with the printed series wherever that series converges (e.g. f bounded on [0, 1] and re s > 1/2 — not printed, not claimed).
