"The given commutators exhibit self-duality within each pair. The natural hypothesis for pair γ would follow the same pattern:
[Ê, Ĥ] = iℏ ŜD̂,   [Ŝ, D̂] = iℏ ÊĤ.   (13.3)
However, the Jacobi identity constrains the missing commutators inconsistently with this extension: applying
[[Ê, Ĥ], D̂] + [[Ĥ, D̂], Ê] + [[D̂, Ê], Ĥ] = 0   (13.4)

## 3 · Formal reading
- **Carrier.** An arbitrary ring that is a ℂ-algebra, `{A : Type u} [Ring A] [Algebra ℂ A]`; the "operators" are elements of A. Commutator [X, Y] = XY − YX (`Ring.lie_def`); iℏ is the scalar `Complex.I * (ħ : ℂ)`, `ħ : ℝ`.
- **Hypotheses (Q7 — the relations appear ONLY as hypotheses; no structure or class carries them).** All six relations enter the derivation, and all six are hypotheses:
  - (3.2) `E * S - S * E = c • (H * D)`; (3.3) `S * H - H * S = c • (D * E)`; (3.4) `H * D - D * H = c • (E * S)`; (3.5) `D * E - E * D = c • (S * H)`;
  - (13.3), first: `E * H - H * E = c • (S * D)`; (13.3), second: `S * D - D * S = c • (E * H)`; with `c = Complex.I * (ħ : ℂ)`.
- **Both relations of (13.3) are used; the print names one.** "with the proposed [Ê, Ĥ] = iℏ ŜD̂" names only the first, but the expansion also needs the second and all four of §3. The derivation, by hand (c = iℏ):
  - [[Ê, Ĥ], D̂] = c[ŜD̂, D̂] = c[Ŝ, D̂]D̂ = c²ÊĤD̂ — uses (13.3) first **and (13.3) second**;
  - [[Ĥ, D̂], Ê] = c[ÊŜ, Ê] = −cÊ[Ê, Ŝ] = −c²ÊĤD̂ — uses (3.4) and (3.2);
  - [[D̂, Ê], Ĥ] = c[ŜĤ, Ĥ] = c[Ŝ, Ĥ]Ĥ = c²D̂ÊĤ — uses (3.5) and (3.3);
  - sum = c²D̂ÊĤ; (13.4) is the Jacobi identity, an identity in every associative ring, so c²D̂ÊĤ = 0.
- **ℏ ≠ 0.** c² = −ℏ²; the print leaves ℏ's non-vanishing implicit; `hħ : ħ ≠ 0` passes from c²D̂ÊĤ = 0 to (13.5) D̂ÊĤ = 0.
- **"Impossible when D̂, Ê, Ĥ are invertible."** In a nontrivial ring (operators on a nonzero space; `Nontrivial A`), a product of units is a unit and so nonzero: the six relations with ℏ ≠ 0 admit no D̂, Ê, Ĥ that are all units (`IsUnit`).
- **"Though not for arbitrary nonzero operators … rather than an outright contradiction."** Read as: the six relations have a realization by nonzero operators, so (13.5) does not by itself make the system contradictory. Witness (L's, not printed): in `Matrix (Fin 2) (Fin 2) ℂ` take Ê = Ŝ = Ĥ = D̂ = N with N = !![0, 1; 0, 0], N² = 0 — every commutator and every product on the right is 0, for every ℏ.
