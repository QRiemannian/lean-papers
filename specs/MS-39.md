## 3 · Formal reading
- **ℒ_s — supplied definition.** MS names ℒ_s as the Mayer transfer operator (Mayer 1991) but **does not print its formula**. The spec uses the formula printed in the companion paper, RZ (8.3) — ℒ_s f(x) = Σ_{n ≥ 1} (x + n)^{−2s} f(1/(x + n)) — specced at L:RZ-53a as `RZ.mayer` (a `tsum`), together with the Gauss map T(x) = {1/x} as `RZ.gaussMap` (L:RZ-53a; `Int.fract x⁻¹`). V₁ decides whether naming the Mayer operator is definite enough to import RZ (8.3) (the same question L:RZ-33a raised for an unprinted χ).
- **Domain — supplied (a wording note, not a CC).** No domain for s is printed at (4.4) or its echo. The printed series Σ_n n^{−2s} converges, and equals ζ(2s), for re(2s) > 1, i.e. **1/2 < re s**; the spec takes that hypothesis. (With `tsum`, outside that half-plane the left side is 0 by convention and the identity would be false; the hypothesis is the series' own convergence domain.)
- **"applied to the constant function and evaluated at x = 0":** (ℒ_s 1)(0) = Σ_{n ≥ 1} n^{−2s} (with f ≡ 1, the summand at x = 0 is n^{−2s}), and that series equals `riemannZeta (2 * s)`. The sum "Σ_n" is over n = 1, 2, … (written `n + 1` over `n : ℕ`).
- **"(ℒ_s 1)(x) = ζ(2s, x + 1), the Hurwitz zeta":** the **classical** Hurwitz zeta ζ(σ, a) = Σ_{n ≥ 0} (n + a)^{−σ} for a > 0. **Caution for L:** mathlib's `HurwitzZeta.hurwitzZeta (a : UnitAddCircle) s` is the 1-periodic version in a; it equals the classical series only for a ∈ [0, 1] (`hasSum_hurwitzZeta_of_one_lt_re`). Here a = x + 1 ∈ [1, 2) and a = φ ≈ 1.618 lie outside [0, 1]: writing `hurwitzZeta φ (2 * s)` would state Σ (n + 1/φ)^{−2s}, a different number. The spec therefore defines the classical series locally. "at a general point" is read on the Gauss-map domain x ∈ [0, 1) (the typing of L:RZ-53a).
- **"at the Gauss-map fixed point x = 1/φ it is ζ(2s, φ)":** two claims: T(1/φ) = 1/φ (1/φ is a fixed point of the Gauss map: 1/(1/φ) = φ and {φ} = φ − 1 = 1/φ), and (ℒ_s 1)(1/φ) = ζ(2s, φ) (classical), since 1/φ + 1 = φ.

## 5 · Intended Lean statement
