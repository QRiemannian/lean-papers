## 3 · Formal reading
- **f.** The print names f only through "the Bernoulli generating function t/(eᵗ − 1)". On ℝ, f(t) = t/(eᵗ − 1) for t ≠ 0, with its removable value f(0) = 1 (the limit). The spec writes this out as a local definition `bernoulliGF` with the `if t = 0 then 1` branch, so that no statement leans on Lean's junk value x/0 = 0. (With the junk value the identities below would also hold at t = 0, but the spec does not rely on it.)
- **(4.2).** For every real t: f(−t) − f(t) = t. (At t = 0 both sides are 0.)
- **"(an even function plus a linear term)".** f = g − t/2 with g even; equivalently t ↦ f(t) + t/2 is even (`Function.Even`). The linear term is −t/2; the print does not name it, (4.2) forces it.
- **Bernoulli sign convention (named).** "The Bernoulli generating function t/(eᵗ − 1)" is mathlib's `bernoulli` convention (B₁ = −1/2, `bernoulli_one`), whose exponential generating function is `bernoulliPowerSeries` with the defining relation `bernoulliPowerSeries_mul_exp_sub_one : bernoulliPowerSeries A * (exp A - 1) = X` — i.e. P = X/(e^X − 1) as a formal power series. mathlib's `bernoulli'` (B₁ = +1/2) is the t/(1 − e^{−t}) convention and is not the paper's. Same convention as `L:RZ-23`.
- **"the symmetry … kills all odd coefficients beyond B₁".** The coefficients are those of the generating function as a power series in t. Two registers are kept apart:
  - the real function f of the display, and
  - the formal series P = `bernoulliPowerSeries ℚ`, whose coefficients are Bₙ/n!.
  The link between them (the Taylor series of f at 0 is P, convergent for |t| < 2π) is not claimed and not needed: the spec states (4.2) a second time at the series level, P(−X) − P(X) = X (f(−X) is `PowerSeries.evalNegHom`), and states the "kills" clause as the implication it prints: **any** formal power series Q over ℚ with Q(−X) − Q(X) = X has coeff n Q = 0 for every odd n > 1. ("Beyond B₁": odd n with 1 < n. The same relation forces coeff 1 Q = −1/2, i.e. B₁ = −1/2 is not killed; that is not part of the clause and is not stated.)
- The vanishing of the Bernoulli numbers themselves, B_{2n+1} = 0 for n ≥ 1, is `L:RZ-23`; this row supplies the mechanism (the symmetry and its implication), not the fact again.

## 5 · Intended Lean statement
**Prose.** Let f(t) = t/(eᵗ − 1) for t ≠ 0 and f(0) = 1. Then (i) f(−t) − f(t) = t for every real t; (ii) t ↦ f(t) + t/2 is even; (iii) at the level of the formal generating function P = Σ Bₙ Xⁿ/n! (mathlib's `bernoulliPowerSeries ℚ`, B₁ = −1/2), P(−X) − P(X) = X; (iv) every formal power series Q over ℚ with Q(−X) − Q(X) = X has all its odd coefficients of index > 1 equal to 0.

**Proposed signature** (shape only):
```lean
/-- The Bernoulli generating function t/(eᵗ − 1) on ℝ, with its removable value 1 at t = 0. -/
noncomputable def bernoulliGF (t : ℝ) : ℝ := if t = 0 then 1 else t / (Real.exp t - 1)

/-- L:RZ-24 · RZ §4.2, Proposition 4.1, (4.2), served p11 (corrected print, CC-1 landed).
The Bernoulli generating function satisfies f(−t) − f(t) = t; f + t/2 is even; the same symmetry
holds for the formal generating function `bernoulliPowerSeries` (convention `bernoulli`, B₁ = −1/2);
and the symmetry kills every odd coefficient beyond the first. -/
theorem rz_24_bernoulli_gf_symmetry :

      ∀ n : ℕ, Odd n → 1 < n → PowerSeries.coeff n Q = 0) := by
  sorry
```
