3. **Formal reading**
   - The Gauss map is T(x) = {1/x} on [0, 1) (display (8.2), `L:RZ-53a`), in Lean `fun x : ℝ => Int.fract x⁻¹`.
   - **Branch n** (n ≥ 1, natural): "implements the Möbius transformation x ↦ 1/(x + n)" is read as: x ↦ 1/(x + n) is an inverse branch of T on [0, 1) — for every x ∈ [0, 1), T(1/(x + n)) = x. (On [0, 1) the denominator x + n ≥ 1 is never 0.)
   - **"given by the matrix (0 1; 1 n)"**: the Möbius action of M_n := !![0, 1; 1, n] on the real projective line (mathlib: GL(2, ℝ) acting on `OnePoint ℝ`) sends the finite point x, x + n ≠ 0, to the finite point 1/(x + n).
   - **"of determinant −1 — an element of GL(2, ℤ)"**: det M_n = −1 over ℤ (a unit, so M_n ∈ GL(2, ℤ)).
   - **"the composition of STⁿ … with the reflection x ↦ −x"**: S = !![0, −1; 1, 0] (z ↦ −1/z; mathlib's `ModularGroup.S`), Tⁿ = !![1, n; 0, 1] (z ↦ z + n; `ModularGroup.coe_T_zpow`), reflection R = !![−1, 0; 0, 1] (x ↦ −x). **Convention named here:** the print does not fix the order of composition; the identity holds with the reflection applied after STⁿ, as matrices M_n = R · (S · Tⁿ), i.e. x ↦ −(−1/(x + n)). The other order, (S · Tⁿ) · R, gives x ↦ 1/(x − n) and is not (8.6). The spec takes the order that makes the printed sentence about (8.6) true; the unit summary names this as the one thing to look at hardest.
   - **"compositions of an even number of branches lie in SL(2, ℤ)"**: for any finite list n₁, …, n_k of positive naturals with k even, det(M_{n₁} ⋯ M_{n_k}) = 1.
   - **(8.7)**: (a) for real x ≠ −1, x = 1/(x + 1) ↔ x² + x − 1 = 0; (b) "the fixed point of the n = 1 branch" is the fixed point in the branch's domain [0, 1) — the quadratic's other root −φ lies outside it — so for x ∈ [0, 1): x = 1/(x + 1) ↔ x = (−1 + √5)/2; (c) (−1 + √5)/2 = φ⁻¹ with φ = `Real.goldenRatio` = (1 + √5)/2.
   - **"In SL(2, ℤ), S² = −I"**: `ModularGroup.S * ModularGroup.S = -1` in `SL(2, ℤ)`.
   - **"in PSL(2, ℤ) S has order 2"**: the image of S in `PSL(2, ℤ)` = SL(2, ℤ) ⧸ centre has `orderOf` 2.
   - **"generating the order-2 orbifold point"**: read as: the image of S generates the PSL(2, ℤ)-stabilizer of i (the order-2 orbifold point; `L:RZ-43b`) — the image of `MulAction.stabilizer SL(2, ℤ) UpperHalfPlane.I` in PSL(2, ℤ) equals `Subgroup.zpowers` of the image of S.
