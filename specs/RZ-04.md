- **"Eigenvalues φ and −1/φ" (convention named).** Read as: the set of real eigenvalues of F equals {φ, −1/φ}. Formal carrier: `spectrum ℝ M` for M : Matrix (Fin 2) (Fin 2) ℝ (the ℝ-algebra spectrum of the matrix); over a field this is exactly the set of roots of `M.charpoly` (`Matrix.mem_spectrum_iff_isRoot_charpoly`, Charpoly/Eigs.lean:80), equivalently the eigenvalues of `Matrix.toLin' M` (`Module.End.hasEigenvalue_iff_isRoot_charpoly`). Set equality states both "these are eigenvalues" and "there are no others", which is what "has … eigenvalues φ and −1/φ" says for a 2×2 matrix. The printed values are written as printed: `-1 / φ` (not `ψ`, though `Real.inv_goldenRatio : φ⁻¹ = -ψ` makes them equal).
- **"Characteristic polynomial λ² − λ − 1 = 0" (convention named).** The "= 0" makes it the characteristic equation; the formal content is `F.charpoly = X ^ 2 - X - 1` in ℤ[X]. Mathlib's `Matrix.charpoly M = det (X·I − M)` is monic, so for 2×2 it is `X ^ 2 - C (trace M) * X + C (det M)` (`Matrix.charpoly_fin_two`) — same sign convention as the print (trace 1, det −1 give X² − X − 1).
