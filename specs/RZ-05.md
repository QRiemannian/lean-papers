## 3 · Formal reading
- **The group and the action.** γ ∈ SL(2, ℝ) acting on ℍ by Möbius maps (mathlib's `UpperHalfPlane.SLAction`, R = ℝ). The sentence is general ("a hyperbolic element"); §2.2 applies it inside SL(2, ℤ) through `Matrix.SpecialLinearGroup.map (Int.castRingHom ℝ)`, which is an instance of the SL(2, ℝ) statement (the convention `rz_63b_geometric` uses).
- **Hyperbolic.** mathlib's `Matrix.IsHyperbolic` (0 < discr = tr² − 4·det; at det 1 this is |tr| > 2), applied to the underlying real matrix — the units' convention across U2/U4.
- **Translation length (convention named).** τ(γ) := inf_{z ∈ ℍ} d(z, γ·z), d mathlib's hyperbolic distance on ℍ (the `MetricSpace ℍ` instance; `UpperHalfPlane.dist_eq`, `cosh_dist`; curvature −1). Carried as a hypothesis `hτ` exactly as in `rz_63b_geometric`, so the definition is visible in the statement.
- **"with eigenvalue λ" (reading named; V₁ to confirm).** λ a real eigenvalue of the matrix: λ ∈ `spectrum ℝ (γ : Matrix (Fin 2) (Fin 2) ℝ)` (U2's RZ-04 convention). A hyperbolic element has the two real eigenvalues λ, λ⁻¹; the print's formula is positive only for the expanding one, so the print means the eigenvalue of modulus > 1 (in the paper's use λ = φ² > 1). The statement takes **1 < |λ|** and writes **ℓ = 2 log |λ|**: for λ > 1 (every positive-trace element, the paper's case) this is the printed ℓ = 2 log λ letter for letter; for a negative-trace element (eigenvalues negative; −γ acts on ℍ as γ does) it is the same length. The absolute value is written out rather than left to mathlib's `Real.log` convention (log x = log |x|, `Real.log_abs`), so the statement does not lean on that convention.
- **log.** `Real.log`, natural (the systole's numeral 4 log φ ≈ 1.9248, L:RZ-06a, fixes the base).
- **§7.2 "Closed-geodesic lengths are ℓγ = 2 log λ".** The same formula; the identification of hyperbolic classes with closed geodesics on X(1) is L:RZ-01 (EFFORT-FAR, cited, outside Q5). Only the formula, as a fact about τ, is taken.
